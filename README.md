# oopsie project

This project was made to be like a game. You can buy robots to use for their intended purpose. You can set the name of the robot, buy premium versions, and there are multiple possible outcomes when performing tasks. 
This project features battery tracking, a robot purchasing system, an econmy/banking system, and tasks.
OOP is applied through multiple classes like the Battery class, Robot, Robot_cleaner, Robot_dog, and Robotcar
Oop encapsilation is implied through these classes where attributes are gotten and set.
Construtors are used in every class when theyt are initilized.
Inheritance is used in Cleaner, the car, and the robot dog because they all inheritaed the robot class to have some starting methods and attributes.
Polymorphism is apllied in do_task with how it is every class but diffrent in each.
Composition is used in every class by using the Battery class to track battery.


Random and a newer version of python are needed to run this file.
